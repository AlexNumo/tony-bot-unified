# TonyBot Unified Platform (Точка переходу)

Єдина інтегрована платформа для онлайн-практикуму «Точка переходу» Антоніни Пашко.
Поєднує в собі:
- Повноцінний Telegram-бот на базі `grammY` (FSM-тест, видача матеріалів, авто-посилання WayForPay, ШІ-підтримка Gemini + Groq).
- Admin CRM & Панель керування розсилками (Express REST API).
- Інтерактивний React веб-інтерфейс (CRM, Симулятор, Керування матеріалами).
- Інтеграція з Supabase PostgreSQL як єдиним джерелом істини.
